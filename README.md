# Boldspace

> **Make room for bold ideas.**  
> Boldspace helps ambitious founders turn promising ideas into real startups with strategy, technology, expertise, and funding.

---

## 🚀 Features

- **Editorial & Modern Design**: Clean typographic hierarchy featuring *Instrument Serif*, *DM Sans*, and *DM Mono*.
- **Interactive Pitch Calculator**: Real-time equity dilution & capital calculator for prospective founders.
- **Dynamic Startup Studio Tracker**: Interactive stage filter and startup showcase with live modal details.
- **Venture Application Modal & Form**: Integrated founder application flow with validation and real-time status feedback.
- **Fully Responsive**: Optimized for desktop, tablet, and mobile screens.
- **Zero Heavy Dependencies**: Built with vanilla HTML5, modern CSS3 (custom properties, responsive grids, and micro-animations), and modular JavaScript.

---

## 🛠️ Tech Stack

- **HTML5**: Semantic markup & accessibility (ARIA, skip links)
- **CSS3**: Custom design tokens, CSS Grid, Flexbox, glassmorphic accents, and smooth transitions
- **JavaScript (ES6+)**: Interactive filtering, calculators, accessible modals, and state handling

---

## 💻 Getting Started

To run locally, simply open `index.html` in your browser or serve using any static server:

```bash
# Using Python 3
python3 -m http.server 8000

# Using Node (npx serve)
npx serve .
```

Open `http://localhost:8000` in your web browser.
